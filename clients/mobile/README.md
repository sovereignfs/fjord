# Fjord Mobile

The iOS and Android client for [Fjord](../../README.md): browse and edit the
repositories you control from your phone, and capture quick notes, offline, as plain
Markdown files. An alternative to Google Keep and Apple Notes for people who want to
own their notes.

**Status: design.** There is no code here yet, only the design and the plan:

- [`DESIGN.md`](DESIGN.md): what Fjord Mobile is, its architecture, and the decisions
  behind it.
- [`ROADMAP.md`](ROADMAP.md): the phases, the tasks, and how each is known to be done.

The format every Fjord client follows is [`spec/SPEC.md`](../../spec/SPEC.md).
