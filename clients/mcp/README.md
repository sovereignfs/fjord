# Fjord for Claude (`fjord-mcp`)

An MCP server that connects Claude to your [Fjord](../../README.md) repository on
GitHub: save documents you write with Claude into a vault, and list, read, search,
check, edit and organise your documents and notes from the conversation. Claude
Desktop and Claude Code run it locally; claude.ai uses a copy you host. ChatGPT
comes next.

**Status: design.** There is no code here yet, only the design and the plan:

- [`DESIGN.md`](DESIGN.md): what `fjord-mcp` is, its architecture, its tools, and
  the decisions behind them.
- [`ROADMAP.md`](ROADMAP.md): the phases, the tasks, and how each is known to be done.

The format every Fjord client follows is [`docs/specs/Fjord.spec.md`](../../docs/specs/Fjord.spec.md).
