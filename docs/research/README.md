# Research

Exploratory documents for open questions that have no concrete design yet: what was read or tried, the findings, the options
and a recommendation. Research comes before an RFC or alongside one. Not every research document becomes one, and a
documented "not now" is a valid outcome.

Files are named `NNNN-short-slug.md`, numbered in order. Each one says what it read or ran, and when, so that a later reader
can tell what has gone stale.
