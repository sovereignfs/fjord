# fjord-thing

[![build](https://example.com/badge.svg)](https://example.com/ci) ![logo](./logo.png "The logo")

A tiny tool. Install with `npm i fjord-thing`, then:

```ts
import { thing } from "fjord-thing";

// Prints "hello"
console.log(thing({ greeting: "hello" }));
```
